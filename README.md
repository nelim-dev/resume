# Resume

Персональное резюме в виде веб-страницы с поддержкой печати в PDF.

## Что это

Сайт-резюме: Frontend / Fullstack-разработчик. Тёмная тема для просмотра в браузере, светлая — для печати и генерации PDF.

## Демо

- **Сайт:** [https://ваш-username.github.io/resume/](https://nelim-dev.github.io/resume/)
- **PDF:** [Bagnenko_Nikolay_CV.pdf](Bagnenko_Nikolay_CV.pdf)

## Стек

- HTML5
- CSS3
- GitHub Pages

## Особенности

- Адаптивная вёрстка
- Тёмная тема на экране, светлая при печати (`@media print`)
- Генерация PDF через `Ctrl+P` из браузера или по нажатию кнопки.
- Семантическая разметка (`header`, `main`, `section`, `article`)
- ATS-совместимая версия PDF

## Структура
```
.
├── index.html # Страница резюме
├── styles.css # Стили (экран + печать)
├── Bagnenko_Nikolay_CV.pdf # PDF-версия
└── README.md
```
## Как получить PDF

1. Открыть `index.html` в Chrome.
2. `Ctrl+P` → «Сохранить как PDF» или по нажатию кнопки «Скачать PDF»
3. Настройки: поля «По умолчанию», фоновая графика — включена, колонтитулы — выключены.
4. Сохранить.
